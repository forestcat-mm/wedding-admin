# 受付 v2.4：受付済タブ・友人圏タグ・強制受付

v2.3（受付の確認ポップアップ）への変更・追加。

## 1. 受付済タブ
- 絞り込みタブは「すべて／未受付／受付済／お渡し物あり」
- 受付済タブの並び：①受付済・お渡し未済（受付済で handed_at が null のお渡し物が残る人）を最上部。行の背景を薄い赤にし、⚠ と「未渡し：お車代」のように項目名を表示 ②残りの受付済を受付時刻の新しい順
- ⚠ の人が 1 人以上いれば受付済タブに「受付済 ⚠2」のように件数を付ける。判定は毎回データから計算する（行のトグルでお渡し済にすれば消える）

## 2. 友人圏タグ
- `GET /api/reception/guests` の各ゲストに `circles: [{ id, name }]`（circles / guest_circles）
- PC は氏名セル内、カードは氏名の下に小さなタグ
- タブの下にタグのチップを横並び（はみ出す分は横スクロール）。選択は 1 つ、「すべて」で解除。サイド・タブ・検索と組み合わせ可。選択中のサイドに該当者がいないタグは出さない

## 3. ポップアップの受付処理（v2.3 からの変更）
- 未チェックのお渡し物がある状態で「受付」：受付せず、赤い帯で「お渡しが済んでいません：お車代」とリマインド、未チェックの枠を赤く、帯の中に「お渡しせずに受付する」（目立たない方のボタン）
- 「お渡しせずに受付する」：チェックした物だけお渡し済にし、受付済を保存。未チェックは未渡しのまま → 受付済タブの上部に ⚠ 付きで出る
- すべてチェック済み（またはお渡し物なし）は v2.3 と同じ
- PC の Enter で押せるのは「受付」だけ。「お渡しせずに受付する」はクリックのみ
