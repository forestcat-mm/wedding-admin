# 臨時ページ：引出物・引菓子 確認リスト — wedding-admin

管理画面に、既存タブとは独立した臨時ページ `/gift-check/` を追加する。最新の引出物・引菓子リストを1行ずつ現物と照合し、確認済みにしていくためのページ。

## 前提
- SQL適用済み：`gift_check_items`（CSVの39行を投入済み。RLSは authenticated のみ）
- 元データ：`01_source/最新_引出物_引菓子一覧_2026-09-25.csv`（参照用。ページはDBから読む）
- データの読み書きは既存の管理画面と同じく supabase-js（ログインユーザー）で行う。Workerの追加は不要

## アクセス
- 既存の管理ページと同じ認証ガード（Supabase Auth ＋ 管理者判定）をかける。受付トークンの端末では権限不足画面を出す
- 上部のタブには追加しない（臨時ページのため）。URLを直接開いて使う
- 静的HTMLにはデータを含めない

## 画面
- 見出し「引出物・引菓子 確認リスト」と、データ日付「2026-09-25版」
- 上部サマリー：確認済 x / 39行、進捗バー。区分ごとに行数・数量・合計金額（税込・実払）を表示する
  - 引出物 26行・84個・¥342,181
  - 引菓子 13行・83個・¥121,618
- 絞り込み：すべて／未確認のみ／差異あり、区分（引出物・引菓子）
- 一覧は区分 → 種類No. の順に並べる。同じ種類No.の複数行（色・季節・地域違い、お茶の組み合わせ違いなど）は、種類ごとの見出しの下にまとめて表示する
- 各行の表示と操作
  - ブランド、商品名、バリエーション・内訳、数量（大きく）、備考
  - 金額（税込単価・小計）は小さく表示する
  - 「確認」チェックボックス（大きめ）：チェックすると checked_at と checked_by（ログインメール）を保存する。外すと null に戻す
  - 「実数」入力欄（任意）：数量と違う値を入れたら、行を赤く強調して「差異 +n / −n」と表示する
  - メモ欄（任意）
  - 保存は入力後に自動で行う。保存中・保存済・失敗が分かる小さな表示を付ける
- 確認済の行は背景を薄い緑にする
- 複数端末で同時に確認できるよう、10秒ごとに再取得する（入力中の行はサーバー値で上書きしない）
- PC（表形式）・スマホ（カード）の両方に対応する。現物を見ながらスマホで操作することを想定し、チェックボックスとタップ領域は大きくする
- 印刷用CSS：チェック欄付きの一覧をA4縦で印刷できるようにする（操作ボタンと入力欄の枠は非表示）

## 完了条件
- 39行すべて表示され、サマリーの行数・数量・合計がSQLの確認クエリと一致する
- チェック・実数・メモが保存され、別の端末にも10秒以内に反映される
- 受付トークンの端末では権限不足画面になる
- 作業後に `00_spec/` にこの仕様書、`01_source/` にCSVを置いた状態でコミットする

## 実装メモ（2026-09-25）
- ファイル：`public/gift-check/`（index.html・gift-check.js・gift-check.css・gift-logic.js）。色とログイン画面は `../style.css` を共用
- 使う列：`id, category, type_no, sort, brand, name, variant, qty, unit_price_ex_tax, unit_price, subtotal, note, checked_at, checked_by, checked_qty, memo, updated_at`。実数は `checked_qty`
- 認証：セッションがあれば Worker の `GET /api/reception/me` に Bearer を付けて `via: 'admin'` を確認（Worker に届かないときはログインのドメインで判定）。セッションがなく受付 Cookie で `via: 'token'` なら権限不足画面（受付画面へのリンク）。管理者でないアカウントは権限不足画面（ログアウト）
- 保存：チェックは即時、実数・メモは入力が止まって 0.7 秒後（Enter・フォーカスを外したときは即時）。変更した列だけを update するので、別の端末で同じ行の別の列を触っても消し合わない。失敗した行は「保存に失敗・再試行」を押すか、次の再取得（10 秒）で送り直す
- 再取得：入力欄にフォーカスがある行・保存待ち・保存中・保存失敗の行、および取得開始より後に保存した行はローカルの値を残す（`mergeRemote`）。タブが非表示の間は取得せず、表示に戻ったときにすぐ取得する
- 絞り込み：「未確認のみ」「差異あり」で操作した行は、絞り込みを切り替えるまで消さずに残す（誤タップを戻せるように）
- 1 行だけの種類は見出しを付けず、その行にブランド・商品名を出す。複数行の種類は見出し（No.・ブランド・商品名・n行・計n個）の下にバリエーションを並べる
- 実数が数量と同じなら「一致」、違えば「差異 +n / −n」（行を赤く）。実数を 0 にしたときも差異として扱う
- 計算は `gift-logic.js`（並び・サマリー・差異・絞り込み・再取得の合成）。`tests/gift-check-logic.test.mjs` で CSV を読み、サマリーが上記の数値と一致することも検証する
