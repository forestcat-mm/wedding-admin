# ご祝儀・内祝い 記録機能 — wedding-admin

いただいたご祝儀と、そのお返し（内祝い）の手配を記録する。ご祝儀の合計と内祝いの購入額は、予算タブに自動で連動させる。

## 前提
- SQL適用済み：`gifts`（ご祝儀）、`gift_givers`（ご祝儀とゲストの紐付け。連名は複数行）、`gift_returns`（内祝い。1つのご祝儀に複数可）。RLSは authenticated のみ
- 集計・予算連動に使う金額は、`gifts.amount_jpy` と `gift_returns.price_jpy + shipping_jpy`
- 削除は論理削除（deleted_at）。既存の管理画面の方式に合わせる
- **実装前に予算タブの既存構造（テーブル・計算方法）を確認し、下記「4. 予算タブとの連動」をどう組み込むかを報告すること。既存データを書き換える必要がある場合は、実装前に止まって質問する**

## セキュリティ
- 金額は機微情報のため、ログインした管理者のみ閲覧・編集できる
- 受付トークンの端末では、他の管理ページと同じく権限不足画面を出す
- 受付APIや招待状サイトのAPIに、ご祝儀の情報を一切含めない
- 変更は既存の change_log に記録する

## 1. 「ご祝儀」タブ（新規）
### 一覧
- 列：贈り主（ゲスト名。連名は「A・B ほか」）、表書きの名義、サイド、種類、金額（円）、内祝い状況、お礼状
- 内祝い状況：不要／未手配／手配中（一部）／発送済／到着済。gift_returns の状態から自動判定する
- 絞り込み：サイド、友人圏、種類、内祝い状況、お礼状。名前での検索
- 並び替え：受け取り日、金額、名前
- 上部に集計カード
  - ご祝儀合計（円）と件数
  - 新郎側・新婦側の内訳
  - 内祝い購入額の合計（商品代＋送料）
  - 内祝い 未手配の件数
- CSV出力：一覧の内容に内祝いの品名・金額を含めたもの（内祝いの手配やお礼状の宛名づくり用）

### 登録・編集フォーム
- 贈り主：ゲストを検索して選ぶ（複数選択可）。ゲスト一覧にいない人は名前を直接入力
- サイド：ゲストを選んだら、そのゲストのサイドを自動で入れる（変更可）
- 表書きの名義、種類（現金／品物／振込／電子送金／その他）
- 金額
  - 通貨の初期値はJPY。JPYのときは円換算額を自動で同じ値にする
  - JPY以外を選んだときだけ「円換算額」の入力欄を出す
  - 種類が品物のときは金額を任意にする
- 受け取り日（初期値 2026-09-26）、経路（受付／当日手渡し／郵送／後日／その他）
- 内祝い要否（初期値：必要）、お礼状、メモ
- 「保存」と「保存して次へ」（フォームを空にして続けて入力できる）。スマホで入力しやすい1画面構成にする

### 内祝いの手配（ご祝儀の詳細画面内）
- ご祝儀1件につき、内祝いを複数登録できる（例：品物＋カタログギフト）
- 項目：品名、購入先・ブランド、商品代（税込）、送料・のし等、状態（予定／注文済／発送済／到着済）、購入日、発送日、注文番号、URL、メモ
- 目安表示：ご祝儀の円換算額の「1/3〜1/2」を参考額として表示し、内祝いの合計額と並べて見せる（表示のみ。制限はしない）

## 2. ゲスト一覧との連携
- ご祝儀をいただいたゲストの行に、小さな「祝」マークを付ける（金額は出さない）
- ゲスト編集画面から、そのゲストのご祝儀の詳細を開けるようにする

## 3. ダッシュボード
- 「ご祝儀」カードを追加：件数、合計（円）、内祝い未手配の件数

## 4. 予算タブとの連動
- 予算タブに、次の2行を**自動連動の行**として表示する
  - 収入「ご祝儀」：gifts の amount_jpy の合計（削除済みを除く）
  - 支出「内祝い」：gift_returns の price_jpy + shipping_jpy の合計（削除済みを除く。状態が「予定」のものは含めない）
- 連動の行は予算タブ上では編集できない。「自動」ラベルを付け、クリックするとご祝儀タブへ移動する
- 予算タブの合計・差引（収支）の計算にこの2行を含める
- 予算データを二重に登録しない（予算タブ側に行をコピーせず、ご祝儀・内祝いのテーブルから毎回集計する）。既存の構造上それが難しい場合は、実装前に方法を提案して質問する

## 完了条件
- ご祝儀の登録・編集・削除ができ、連名・ゲスト外の贈り主・外貨にも対応している
- 内祝いを複数登録でき、状態に応じて一覧の内祝い状況が変わる
- ご祝儀・内祝いを登録・変更すると、予算タブの収入・支出と収支に反映される
- 受付トークンの端末や受付APIから、ご祝儀の情報が見えない
