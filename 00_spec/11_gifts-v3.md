# ご祝儀 v3：並び順・出欠表示・引出物記録・品物の相当額 — wedding-admin

`00_spec/gifts-v2.md` への追加変更。v2の内容はこの仕様で変更する箇所を除いてすべて維持する。v2が未実装なら、v2とあわせて実装する。

## 前提
- SQL適用済み（`gifts-v3.sql`）
  - `gifts.attendance`：attended（出席）／absent（欠席の招待客）／uninvited（招待なし）
  - `gifts.return_policy`：needed（内祝い必要）／hikidemono（不要・引出物お渡し済）／not_needed（不要・その他）。v2の return_needed はこれに置き換えて削除済み
  - `gifts.goods_value_jpy`：品物の相当額
  - `gift_hikidemono`：お渡しした引出物・引菓子（gift_check_item_id は引出物・引菓子リスト `gift_check_items` の行。テーブルがあればFK付き）
- v2のコードで return_needed を参照している箇所は、すべて return_policy に置き換える

## 1. 並び順：同行者はメイン招待者の直後
- 一覧は「組」（同じ回答の本人＋同行者）を単位に並べる
  - 並び替え（名前・サイド・金額など）は組の本人の値で行い、同行者は常に本人の直後に続ける
  - 同行者の行は字下げし、「同行」ラベルを付ける
- 連名にまとめた行は、まとめた中の先頭の贈り主の位置に1行で表示する
- 手動登録（欠席・招待なし）の行は、贈り主の名前で同じ並び順に混ぜる

## 2. 披露宴の出欠の表示
- 一覧に「出欠」列を追加する：出席／欠席／招待なし（色分けしたラベル）
- 設定のルール
  - 出席者から自動作成した行：attended
  - 手動登録で、欠席の招待客をゲスト一覧から選んだ場合：absent
  - 手動登録で、名前を直接入力した場合：uninvited（詳細画面で absent に変更可）
- 絞り込みに「出欠」（すべて／出席／欠席／招待なし）を追加する

## 3. 内祝いの要否と、お渡しした引出物・引菓子
### 内祝いの要否
- 詳細画面の「内祝い」欄を3択にする：必要／不要（引出物お渡し済）／不要（その他）
- 初期値
  - 出席（attended）の行：不要（引出物お渡し済）
  - 欠席・招待なしの行：必要
- 一覧の内祝い状況
  - 不要（引出物お渡し済）の行は「引出物済」と表示する
  - 不要（その他）の行は「不要」と表示する
  - 必要の行は、v1・v2と同じく gift_returns の状態から判定する（未手配／手配中／発送済／到着済）
- 集計カードの「内祝い 未手配」は、必要の行だけを数える

### お渡しした引出物・引菓子の記録
- 詳細画面に「お渡しした引出物・引菓子」欄を追加する（1件のご祝儀に複数行）
  - 引出物・引菓子リスト（gift_check_items）から選ぶと、区分・品名・税込単価を自動入力する（編集可）
    - 同じ種類No.で色違いなどがある場合は、選択肢に「バリエーション・内訳」も表示する
    - gift_check_items が存在しない環境では、手入力のみにする
  - リストにない物は、区分（引出物／引菓子／その他）・品名・単価を手入力する
  - 数量（初期値1）、メモ
- 詳細画面に、お渡しした物の合計額を表示する
- v1の目安表示（ご祝儀の1/3〜1/2）の横に、「お渡し済み：引出物・引菓子 ¥合計」も並べて表示する
- 引出物・引菓子の金額は予算タブに連動させない（予算にはホテルの請求として計上済みのため、二重計上を避ける）

### 一括入力
- 一覧で複数行をチェックし、「引出物・引菓子をまとめて設定」から、同じ品物を選んだ行にまとめて登録できるようにする（テーブルごとに同じ引出物を渡した場合などを想定）

## 4. 品物でいただいた場合の相当額
- 種類が「品物」のとき、詳細画面に「相当額（円）」の入力欄を出す（goods_value_jpy）
- 相当額は、ご祝儀の金額（expected_jpy・amount_jpy）とは別に扱う
  - ご祝儀の合計・内訳・予算タブの収入には含めない
  - 一覧の金額列には、ご祝儀の金額とは別に「品物 ¥相当額」と小さく表示する
- 集計カードに「品物（相当額）の合計 ¥x・n件」を別に表示する
- 現金と品物の両方をいただいた場合は、同じ1件に金額と相当額の両方を入れられるようにする（種類とは関係なく、相当額の欄を「品物もいただいた」のチェックで表示できるようにする）
- 内祝いの目安表示（1/3〜1/2）は、ご祝儀の金額＋品物の相当額を基準に計算する

## 5. CSV出力
- 列を追加する：出欠、内祝いの要否、お渡しした引出物・引菓子（品名をまとめて1セル）、その合計額、品物の相当額

## 完了条件
- 同行者が本人の直後に並び、並び替えをしても組が崩れない
- 出欠が表示され、絞り込める
- 出席の行は初期値が「不要（引出物お渡し済）」になり、未手配の件数に数えられない
- 引出物・引菓子をリストから選んで記録でき、単価が自動で入る
- 品物の相当額が、ご祝儀の合計と予算タブの収入に含まれない
